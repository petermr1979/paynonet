🎨 Конвертация иконок

Для работы PWA необходимы PNG иконки. Выберите удобный способ конвертации.

180×180
Apple Touch
192×192

512×512
PWA

Способ 1: Онлайн-конвертеры (рекомендуется)

  1. Откройте svgtopng.com
  2. Загрузите файл assets/icons/icon.svg
  3. Укажите размер 180×180
  4. Скачайте как apple-touch-icon.png
  5. Повторите для других размеров

Полезные сервисы:

SVG to PNG CloudConvert Favicon Generator

Способ 2: ImageMagick (локально)

Установите ImageMagick и запустите скрипт:

brew install imagemagick
./convert-icons.sh

Способ 3: Figma / Sketch

  1. Импортируйте SVG файл в Figma
  2. Создайте фреймы 180×180, 192×192, 512×512
  3. Экспортируйте как PNG

📁 Куда сохранить файлы

Поместите PNG файлы в папку assets/icons/:

  • apple-touch-icon.png (180×180)
  • icon-192.png (192×192)
  • icon-512.png (512×512)
