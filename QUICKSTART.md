# 🚀 Быстрый старт PNN Wallet

## 1. Генерация иконок (обязательно для PWA)

### Вариант A: Через браузер (самый простой)
1. Откройте `icon-generator.html` в браузере
2. Нажмите кнопку "📥 Скачать все иконки"
3. Сохраните файлы в папку `assets/icons/`:
   - `apple-touch-icon.png` (180×180)
   - `icon-192.png` (192×192)
   - `icon-512.png` (512×512)

### Вариант B: Онлайн-конвертеры
1. Откройте `convert-icons-guide.html` в браузере
2. Следуйте инструкциям для конвертации SVG в PNG

### Вариант C: ImageMagick (если установлен)
```bash
./convert-icons.sh
```

## 2. Запуск приложения

### Локальный сервер (для разработки)
```bash
# Python 3
python3 -m http.server 8000

# Node.js
npx http-server -p 8000

# PHP
php -S localhost:8000
```

Приложение доступно по адресу: http://localhost:8000

## 3. Установка на iPhone

1. Откройте `http://[ваш-IP]:8000` в Safari на iPhone
   - Или загрузите на HTTPS хостинг (GitHub Pages, Vercel, Netlify)
2. Нажмите кнопку **Поделиться** (квадрат со стрелкой)
3. Выберите **«На экран "Домой"»**
4. Нажмите **«Добавить»**

## 4. Проверка функциональности

### Главное экран
- ✅ Логотип приложения в центре
- ✅ Кнопка "+" в правом верхнем углу
- ✅ Пустое состояние (если нет карт)

### Добавление карты
1. Нажмите кнопку "+"
2. Введите номер карты (например: 4111111111111111)
3. Срок действия (12/25)
4. CVV (123)
5. Имя держателя (IVAN IVANOV)
6. Нажмите "Добавить"

### Основная карта
- Нажмите на звёздочку справа от карты
- Основная карта выделяется градиентным фоном

## 6. Публикация в интернете

### GitHub Pages (бесплатно)
1. Создайте репозиторий на GitHub
2. Загрузите все файлы
3. Включите GitHub Pages в настройках
4. Приложение доступно по HTTPS

### Vercel/Netlify (бесплатно)
1. Зарегистрируйтесь на vercel.com или netlify.com
2. Перетащите папку с файлами
3. Получите HTTPS ссылку мгновенно

## 7. Тестирование на iPhone

### Требования
- iOS 16.0 или выше
- Safari (последняя версия)
- HTTPS соединение (или localhost)

### Проверка PWA
1. Откройте приложение в Safari
2. Должна появиться кнопка "На экран Домой"
3. После установки приложение открывается без интерфейса Safari
4. Работает офлайн (после первого посещения)

## 🎨 Дизайн-система

### Glass Morphism
- Полупрозрачные карточки: `rgba(255, 255, 255, 0.75)`
- Размытие фона: `backdrop-filter: blur(20px)`
- Мягкие тени: `box-shadow: 0 8px 32px rgba(0, 0, 0, 0.1)`

### Анимации
- Плавные переходы: `0.3s cubic-bezier(0.4, 0, 0.2, 1)`
- Spring-эффект: `cubic-bezier(0.34, 1.56, 0.64, 1)`

### Шрифты
- SF Pro: `-apple-system, BlinkMacSystemFont`
- Адаптивный кегль: 11px - 34px

## 📊 Метрики производительности

- Время запуска: < 1 секунды
- FPS: 60/120 (на устройствах с ProMotion)
- Размер: ~50 KB (без иконок)

## 🐛 Решение проблем

### Иконки не отображаются
- Убедитесь, что PNG файлы в папке `assets/icons/`
- Проверьте имена файлов (чувствительно к регистру)

### PWA не устанавливается
- Требуется HTTPS (кроме localhost)
- Проверьте manifest.json через Chrome DevTools

### Service Worker не работает
- Очистите кэш Safari
- Проверьте консоль на ошибки
