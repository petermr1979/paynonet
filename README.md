# PNN - Заплати Без Сети (MVP v1)

Progressive Web App для оплаты картами «Мир» без интернета через BLE (технология «Волна» от НСПК).

## Возможности MVP

✅ **Визуальная демонстрация UX-концепции:**
- Glass Morphism дизайн в стиле iOS 16+
- Вертикальная карусель карт с эффектом глубины
- Смахивание вправо для запуска передачи токена
- Анимация «гиперпространства» (звёздные линии)
- Модальное окно добавления карты с flip-up анимацией
- Валидация BIN карт платёжной системы «Мир»

⚠️ **Ограничения MVP:**
- Нет реальной интеграции с сервером НСПК
- Токенизация — фейковая генерация
- BLE-передача — визуальная симуляция
- Валидация карты — только форматная

## Быстрый старт

### 1. Локальный запуск (для разработки)

```bash
# Через Python 3
python3 -m http.server 8000

# Или через Node.js (требуется http-server)
npx http-server -p 8000

# Или через PHP
php -S localhost:8000
```

Откройте в браузере: `http://localhost:8000`

### 2. Запуск на iPhone (для тестирования PWA)

**Вариант A: Через локальную сеть**
```bash
# Узнать IP-адрес компьютера
ipconfig getifaddr en0  # macOS

# Запустить сервер на этом IP
python3 -m http.server 8000 --bind 0.0.0.0
```

На iPhone откройте: `http://<ваш-IP>:8000`

**Вариант B: Через HTTPS туннель (ngrok)**
```bash
ngrok http 8000
```

Откройте полученную HTTPS-ссылку на iPhone.

### 3. Установка на домашний экран iPhone

1. Откройте сайт в Safari
2. Нажмите кнопку «Поделиться» (квадрат со стрелкой)
3. Выберите «На экран «Домой»»
4. Подтвердите установку

Приложение откроется в режиме PWA (без адресной строки).

## Тестирование функций

### Добавление карты
1. Нажмите кнопку «+» в правом верхнем углу
2. Введите номер карты (начинается с `2200` для «Мир»)
   - Пример: `2200 1234 5678 9012`
3. Срок действия: `12/25`
4. CVV: `123`
5. Имя: `IVAN IVANOV`
6. Нажмите «OK»

### Передача токена
1. Смахните активную карту вправо
2. Запустится анимация «гиперпространства»
3. Через 3 секунды возврат к основному экрану

### Навигация
- **Вкладки внизу**: «Главная» / «История» (заглушка)
- **Аватарка сверху**: заглушка личного кабинета
- **Свайп влево/вправо**: переключение карт

## Технические детали

### Glass Morphism эффекты
```css
backdrop-filter: blur(20px);
-webkit-backdrop-filter: blur(20px);
background: rgba(255, 255, 255, 0.08);
border: 1px solid rgba(255, 255, 255, 0.15);
```

### BIN-коды «Мир» для валидации
- `2200` - `2209`
- `221` - `229`
- Полный диапазон: `220000` - `229999`

### PWA требования
- HTTPS (кроме localhost)
- Service Worker зарегистрирован
- manifest.json с иконками
- Meta-теги для iOS
