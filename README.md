# PNN - Заплати Без Сети (MVP v1)

Progressive Web App для iPhone с дизайном в стиле Glass Morphism, вдохновлённым интерфейсами iOS 16+.

## 🎯 Описание

PNN - это демонстрационное PWA-приложение, показывающее концепцию оплаты с помощью BLE-токенизации «Волна» от НСПК. Приложение работает офлайн и поддерживает установку на домашний экран iPhone.

## ✨ Особенности MVP v1

### Визуальные
- **Glass Morphism дизайн** - полупрозрачные слои с размытием (backdrop-filter)
- **Анимация гиперпространства** - эффект "звёздных войн" при передаче токена
- **Карусель карт** - плавный 3D-скроллинг платёжных карт
- **Свайп-жесты** - интуитивное управление картами

### Технические
- **PWA** - установка на домашний экран, офлайн-работа
- **IndexedDB** - локальное хранение данных
- **Web Crypto API** - базовое шифрование токенов
- **Service Worker** - кэширование для офлайн-доступа
- **Адаптивность** - под iPhone 6.1" и 6.7"

## 🚀 Быстрый старт

### Вариант 1: Локальный сервер (рекомендуется)

```bash
# Через Python 3
python3 -m http.server 8000

# Через Node.js (требуется http-server)
npx http-server -p 8000

# Через PHP
php -S localhost:8000
```

Затем откройте в браузере: `http://localhost:8000`

### Вариант 2: VS Code Live Server

1. Установите расширение "Live Server"
2. Откройте `index.html`
3. Нажмите "Go Live"

## 📱 Установка на iPhone

### Через Safari

1. Откройте приложение в Safari
2. Нажмите кнопку "Поделиться" (квадрат со стрелкой)
3. Выберите "На экран «Домой»"
4. Подтвердите установку

### Требования для установки

- HTTPS соединение (или localhost)
- Валидный `manifest.json`
- Зарегистрированный Service Worker
- Иконки нужных размеров

## 🎮 Использование

### Навигация
- **Главная** - просмотр и управление картами
- **История** - заглушка (в разработке)

### Управление картами
- **Свайп влево** - следующая карта
- **Свайп вправо** - передача токена (оплата)
- **Тап на аватар** - личный кабинет (заглушка)
- **Тап на "+"** - добавить новую карту

### Добавление карты
1. Нажмите "+" в верхней панели
2. Введите данные карты:
   - Номер (16 цифр)
   - Срок действия (MM/YY)
   - CVV (3 цифры)
   - Имя держателя
3. Нажмите "Добавить карту"

### Передача токена
1. Выберите нужную карту
2. Свайпните вправо
3. Дождитесь завершения анимации "гиперпространства"
4. Токен "передан" (в MVP - симуляция)

## 🎨 Дизайн

### Цветовая палитра
```css
--bg-primary: #0a0a1a      /* Тёмно-синий фон */
--accent-primary: #00d4ff   /* Голубой акцент */
--accent-secondary: #7b2fff /* Фиолетовый акцент */
--glass-bg: rgba(255,255,255,0.08) /* Полупрозрачный фон */
```

### Glass Morphism эффекты
- `backdrop-filter: blur(20px)` - размытие фона
- Полупрозрачные градиенты
- Светящиеся границы
- Мягкие тени

## 🔧 Технические детали

### Хранение данных
- **IndexedDB** - карты, транзакции, настройки
- **localStorage** - ключ шифрования, флаги
- **Шифрование** - XOR (для MVP, в production использовать AES-GCM)

### Service Worker
- Кэширование статических ресурсов
- Offline-first стратегия
- Фоновая синхронизация (заготовка)

### Анимации
- **CSS Transitions** - плавные переходы
- **Web Animations API** - сложные анимации
- **Canvas** - анимация гиперпространства

## 🚧 Ограничения MVP

### Функциональные
- ❌ Нет интеграции с сервером
- ❌ Нет реальной токенизации (фейковый токен)
- ❌ BLE-передача - визуальная симуляция
- ❌ Нет валидации PCI DSS
- ❌ Личный кабинет - заглушка
- ❌ История операций - пуста

### Технические
- ⚠️ Простое шифрование (XOR)
- ⚠️ Нет биометрической аутентификации
- ⚠️ Нет Web Bluetooth API реализации

## 🛠 Разработка

### Генерация иконок

1. Откройте `icons/generate-icons.html` в браузере
2. Нажмите "Сгенерировать иконки"
3. Все иконки скачаются автоматически

Или используйте `icons/icon.svg` в любом векторном редакторе (Figma, Sketch).

### Сборка для production

```bash
# Минификация CSS (опционально)
npm install -g clean-css-cli
cleancss -o styles/main.min.css styles/main.css

# Минификация JS (опционально)
npm install -g uglify-js
uglifyjs js/*.js -o js/bundle.min.js -c -m
```

### Тестирование PWA

1. Откройте Chrome DevTools
2. Перейдите на вкладку "Application"
3. Проверьте:
   - Manifest
   - Service Worker
   - Cache Storage
   - IndexedDB
