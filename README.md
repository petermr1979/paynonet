# PNN Wallet - PWA для iPhone

Приложение для управления банковскими картами в стиле Glass Morphism для iOS 16+.

## 🚀 Возможности

- **Glass Morphism дизайн** - полупрозрачные элементы с размытием в стиле iOS 16+
- **PWA поддержка** - установка на домашний экран iPhone
- **Офлайн работа** - Service Worker для кэширования
- **Автоформатирование** - автоматическое форматирование номера карты, срока действия
- **Определение платёжной системы** - Visa, Mastercard, МИР
- **Основная карта** - выбор карты для оплаты по умолчанию
- **iOS-анимации** - плавные переходы и анимации в стиле Human Interface Guidelines

## 🛠 Установка и запуск

### Вариант 1: Локальный сервер (рекомендуется для разработки)

```bash
# Через Python 3
python3 -m http.server 8000

# Через Node.js (требуется http-server)
npx http-server -p 8000

# Через PHP
php -S localhost:8000
```

### Вариант 2: GitHub Pages

1. Загрузите файлы в репозиторий GitHub
2. Включите GitHub Pages в настройках репозитория
3. Приложение будет доступно по адресу `https://username.github.io/repo-name/`

### Вариант 3: Любой статический хостинг

Загрузите все файлы на любой хостинг с поддержкой HTTPS (обязательно для PWA).

## 📱 Установка на iPhone

### Требования
- iOS 16.0 или выше
- Safari (последняя версия)
- HTTPS соединение (или localhost для разработки)

### Инструкция по установке

1. Откройте приложение в Safari на iPhone
2. Нажмите кнопку **Поделиться** (квадрат со стрелкой вверх)
3. Прокрутите вниз и выберите **«На экран „Домой"»**
4. Введите название (например, "PNN Wallet")
5. Нажмите **«Добавить»** в правом верхнем углу

Приложение появится на домашнем экране и будет запускаться как нативное.

## 🎨 Дизайн-система

- **Primary**: `#667eea` (фиолетово-синий)
- **Secondary**: `#764ba2` (фиолетовый)
- **Background**: `#f5f5f7` (светло-серый Apple)

- **Прозрачность**: `background: rgba(255, 255, 255, 0.75)`
- **Граница**: `border: 1px solid rgba(255, 255, 255, 0.5)`

### Шрифты
- **Семейство**: `-apple-system, BlinkMacSystemFont, SF Pro Text`
- **Размеры**: 11px, 13px, 15px, 17px, 20px, 24px, 34px

## 🔧 Конвертация SVG иконок в PNG

Для работы PWA необходимы PNG иконки. Конвертируйте SVG файлы:

### Через командную строку (требуется ImageMagick)

```bash
# Apple Touch Icon (180x180)
convert assets/icons/icon.svg -resize 180x180 assets/icons/apple-touch-icon.png

# Icon 192x192
convert assets/icons/icon-192.svg -resize 192x192 assets/icons/icon-192.png

# Icon 512x512
convert assets/icons/icon-512.svg -resize 512x512 assets/icons/icon-512.png
```

### Через онлайн-конвертеры
- [SVG to PNG Converter](https://svgtopng.com/)
- [CloudConvert](https://cloudconvert.com/svg-to-png)

### Через Figma/Sketch
1. Импортируйте SVG файл
2. Экспортируйте как PNG с размерами 180x180, 192x192, 512x512

## 🎯 Основные функции

### Добавление карты
1. Нажмите кнопку **«+»** в правом верхнем углу
2. Введите номер карты (автоформатирование каждые 4 цифры)
3. Введите срок действия в формате ММ/YY
4. Введите CVV-код (3-4 цифры)
5. Введите имя держателя карты (опционально)
6. Нажмите **«Добавить»**

### Выбор основной карты
- Нажмите на **звёздочку** справа от карты
- Основная карта выделяется градиентным фоном

### Удаление карты
- В разработке (планируется свайп влево)

## 📊 Производительность

### Оптимизация
- **CSS containment** для изоляции компонентов
- **will-change** для анимированных элементов
- **RequestAnimationFrame** для плавных анимаций
- **Debounced input** для обработки ввода
- **Lazy rendering** для карточек

### Метрики
- **Время запуска**: < 1 секунды
- **FPS**: 60/120 (на устройствах с ProMotion)
- **Размер приложения**: < 100 KB (без иконок)

## 🔒 Безопасность

- Данные хранятся только в **localStorage** устройства
- Номер карты маскируется (показываются только последние 4 цифры)
- CVV-код не сохраняется
- HTTPS обязателен для Production

## 🌐 Поддерживаемые устройства

- iPhone 8 и новее
- iOS 16.0 и выше
- Safari 16.0 и выше

### Тестирование на разных устройствах
- iPhone SE (2-3 поколение)
- iPhone 12/13/14/15
- iPhone 15 Pro/Pro Max (с учётом Dynamic Island)

## 🐛 Известные ограничения

1. **Service Worker** не работает в режиме инкогнито
2. **PWA установка** доступна только через Safari (не через Chrome на iOS)
3. **backdrop-filter** может потреблять больше батареи на старых устройствах
