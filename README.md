# PNN Wallet - PWA приложение для iOS

Мобильное приложение для управления банковскими токенами, разработанное исключительно для платформы iOS (iPhone) в формате Progressive Web App (PWA).

## Требования

- **Минимальная версия iOS**: 16.0
- **Браузер**: Safari (рекомендуется) или любой современный браузер
- **Формат**: PWA (устанавливается на домашний экран)

## Установка и запуск

### Вариант 1: Локальный запуск (для разработки)

1. Откройте терминал и перейдите в директорию проекта:
```bash
cd /path/to/PNN_7
```

2. Запустите локальный сервер (требуется Python 3):
```bash
python3 -m http.server 8000
```

Или используйте Node.js с пакетом `serve`:
```bash
npx serve .
```

3. Откройте в браузере: `http://localhost:8000`

### Вариант 2: Развертывание на хостинге

1. Загрузите все файлы на HTTPS хостинг (обязательно для PWA)
2. Откройте сайт в Safari на iPhone
3. Нажмите "Поделиться" → "На экран «Домой»"

## Функциональность

### Главный экран

- **Header**: Логотип, кнопка профиля, кнопка добавления карты
- **Карточки токенов**: Сетка карт разных банков с цветовой кодировкой
- **Большая карта**: Интерактивная карта с режимом оплаты
- **Tab Bar**: Навигация между "Основное" и "История"

### Добавление карты

1. Нажмите кнопку "+" в правом верхнем углу
2. Заполните форму:
   - Номер карты (16-19 цифр, авто-форматирование)
   - Срок действия (MM/YY, валидация даты)
   - CVV (3 цифры, опционально)
3. Нажмите на звезду, чтобы сделать карту основной
4. Нажмите "OK" для добавления

### Режим оплаты

1. Свайпните большую карту справа налево
2. Активируется эффект "полета" (Star Wars style)
3. Нажмите "ОТМЕНА" для выхода

## Технические особенности

### PWA возможности

- **Service Worker**: Кэширование ресурсов для офлайн-работы
- **Manifest**: Установка на домашний экран
- **Viewport**: Адаптация под safe area iPhone

### Производительность

- **Скорость запуска**: < 2 секунд
- **FPS**: Стабильные 60 FPS (120 FPS на ProMotion)
- **Оптимизация**: CSS containment, will-change, requestAnimationFrame

### Совместимость

- iOS 16.0+
- Safari 16+
- Поддержка темной темы (автоматически)

## Интеграция с НСПК

В текущей версии интеграция с сервером НСПК не активна. При добавлении карты показывается индикатор загрузки (2 секунды).

Для активации интеграции измените метод `handleCardSubmit` в файле `js/app.js`:

```javascript
  this.cardRenderer.addCard(card);

  // });

  await LoadingAnimations.hide(this.elements.loadingOverlay);
}
```
